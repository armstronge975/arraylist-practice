# arraylist-practice

Instructions:
1. Create a new Java program that uses the scanner to add numbers into an arraylist until the user types in 0. (duplicates are fine).
2. The screen should give the following options for the user to do next:
a. Print out the whole arraylist
b. Edit the array (replace a specific location's value)
c. Delete a value from the array
d. Add a new value to the end of the arraylist
e. Find the location of a given value
f. Quit the program

Use W3Schools and the javadocs for guides on how to interact with an arraylist: https://www.w3schools.com/java/java_arraylist.asp, https://docs.oracle.com/javase/8/docs/api/java/util/ArrayList.html
